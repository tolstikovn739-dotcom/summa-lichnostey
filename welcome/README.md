# Сумма Личностей — презентация

Отдельная презентационная страница с оригинальными анимациями в стиле Island и фирменными цветами команды.

Адрес: https://tolstikovn739-dotcom.github.io/summa-lichnostey/welcome/
Предпросмотр: https://summa-universe.azurepaver2.chatgpt.site/

Статический HTML/CSS/JS; сборка не нужна. Шрифты и портреты локальные. Демо ленты, коллекции, оформления профиля и двустороннего обмена не обращаются к Firebase и не меняют данные игроков. Ссылки ведут на основной сайт и последнюю APK-версию.

Прокрутка на телефонах без закреплённых сцен; анимации учитывают prefers-reduced-motion.
